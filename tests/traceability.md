# 기능 001 요구사항·테스트 추적 대조표

기능 001(`project-path-gateway`)의 수용 시나리오·경계 사례와 기존 테스트 함수가 어떤 dry-run 사례와 수동 확인 절차로 옮겨졌는지
적는다. 사례 식별자는 `<사례 파일 경로>:<사례 이름>`이고, 수동 확인 번호는 [manual-checks.md](./manual-checks.md)의 절 번호다.
`sh scripts/lint.sh`가 모든 사례 식별자와 절 번호가 실제로 있는지 확인한다.
